# Prototipi — Piattaforma Permessi PDP Box Doccia

Prototipi HTML statici delle viste della piattaforma di gestione permessi, prodotti in Fase 2 del progetto come base visuale per la revisione col committente e per lo sviluppo Livewire successivo.

**Nota:** questo materiale contiene solo dati fittizi, logo placeholder, nessuna informazione reale. I prototipi non sono l'applicazione finale: sono mockup navigabili usati per validare layout, flussi e lessico prima dell'implementazione funzionale.
